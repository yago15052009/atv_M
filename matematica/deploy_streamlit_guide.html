Estrutura

Organização da Pasta do Projeto

Arquivos mínimos necessários

Certifique-se de que a pasta do projeto contenha ao menos estes dois arquivos essenciais:

app.py

Arquivo principal com o código Python

Obrigatório

requirements.txt

Bibliotecas Python utilizadas

Obrigatório
requirements.txt 
streamlit
pandas
numpy
3
Validação

Teste Local do Aplicativo

Valide antes de publicar

Antes de enviar os arquivos para a nuvem, verifique o funcionamento local executando o comando abaixo no terminal da pasta do seu projeto:

Terminal 
streamlit run app.py

Acesse a URL indicada no terminal para validar a aplicação. Após a verificação, encerre o processo pressionando Ctrl + C.

4
Git & GitHub

Criação e Envio ao GitHub

Inicialize o repositório e faça o push

Acesse o GitHub e crie um novo repositório (Público ou Privado). Em seguida, execute os comandos abaixo no terminal da pasta do projeto:

Código Python / Streamlit 
git init
git add .
git commit -m "Commit inicial da aplicacao Streamlit"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
5
Deploy!

Execução do Deploy no Streamlit Cloud

Configure e publique sua aplicação

1. Acesse share.streamlit.io e faça login com sua conta GitHub.

2. Clique em Create app e selecione a opção de importação de repositório existente.

3. Preencha os campos conforme a tabela abaixo e clique em Deploy!

Campo Descrição Exemplo
Repository Nome do repositório no GitHub seu-usuario/meu-app
Branch Ramificação com a versão final main
Main file path Caminho para o arquivo principal app.py
App URL (Opcional) Subdomínio personalizado meu-app.streamlit.app
6
Avançado

Configurações Adicionais e Manutenção

Secrets, variáveis de ambiente e atualizações

Variáveis de Ambiente / Secrets

Para usar chaves secretas com segurança, acesse Settings › Secrets no painel do Streamlit Cloud. Defina as variáveis no formato TOML e acesse via st.secrets["NOME_DA_CHAVE"].

# secrets.toml (no painel)
MINHA_CHAVE = "valor-secreto"

# Acesso no Python
chave = st.secrets["MINHA_CHAVE"]

Atualizações Automáticas

Qualquer novo commit e push enviado para a branch main no GitHub atualizará o aplicativo publicado automaticamente na nuvem.

git add .
git commit -m "Nova funcionalidade"
git push origin main
